# Native Proc and Free move API audit — alpha.15

Target: Retail **12.1.0, build 69933**. The API/source audit is pinned to Blizzard UI source mirror commit [`09b9db7948abc9b9648dedaab51eb0cf3ee67b31`](https://github.com/Gethe/wow-ui-source/tree/09b9db7948abc9b9648dedaab51eb0cf3ee67b31). Source declarations establish an allowed implementation path; they do not replace target-client combat, taint, visual, or performance testing.

## Selected combat path

CarGOUI creates a native `AuraContainer` with `CustomAuraContainerTemplate`, sets its unit to `player`, and adds a fixed aura slot with `HELPFUL` and a verified `includeSpellIDs` map. This is the supported inbound API. The native implementation explicitly permits spell identity filtering for helpful auras on assistable units. It handles aura membership and replacement internally; CarGOUI does not enumerate buffs or receive the matched aura data. Only the current class/specialization's eligible Proc definitions are activated. Free move uses the current class's confirmed Time Spiral receiver aura. [Custom container API and filter validation](https://github.com/Gethe/wow-ui-source/blob/09b9db7948abc9b9648dedaab51eb0cf3ee67b31/Interface/AddOns/Blizzard_AuraContainer/Blizzard_CustomAuraContainer.lua), [native matching rules](https://github.com/Gethe/wow-ui-source/blob/09b9db7948abc9b9648dedaab51eb0cf3ee67b31/Interface/AddOns/Blizzard_AuraContainer/Blizzard_AuraContainerUtil.lua).

Each Proc slot registers only a FontString using `SetDurationText`. The supplied duration binding is a presentation template: one decimal place, real-time modifier, empty expired/zero-duration text. Blizzard copies it and supplies the slot's real aura duration. There is no name, icon, backdrop, application-count display, or manually calculated expiry. The native button retains a stable DurationObject and updates it from actual aura data when the aura is assigned, refreshed, or cleared. This implementation does **not** call `C_UnitAuras.GetAuraDuration` from addon Lua. [Native duration ownership](https://github.com/Gethe/wow-ui-source/blob/09b9db7948abc9b9648dedaab51eb0cf3ee67b31/Interface/AddOns/Blizzard_AuraContainer/Blizzard_AuraButton.lua), [native text binding and visibility](https://github.com/Gethe/wow-ui-source/blob/09b9db7948abc9b9648dedaab51eb0cf3ee67b31/Interface/AddOns/Blizzard_AuraContainer/Blizzard_CustomAuraButton.lua).

Free move registers the static public string `Free move` inside its filtered native slot. Native aura presence shows or hides that child. It has no countdown binding, fixed lifetime, cast counter, or action-button-glow inference. A remaining charge is not used to infer the effect. The user's confirmation identifies Time Spiral as the intended feature; the class receiver IDs remain separately source-audited data.

## Why direct aura queries are not the fallback

`GetPlayerAuraBySpellID` and `GetUnitAuraBySpellID` require a non-secret aura. Index/instance queries require aura access, and `UNIT_AURA` can carry a secret payload. A nil result is not sufficient evidence that a tracked effect is absent. CarGOUI therefore does not use these queries, inspect `AuraData`, compare applications, branch on an expiration time, or catch errors as a presence test. `C_UnitAuras.GetAuraDuration` also requires valid instance/access conditions; merely knowing an overlay's spell ID does not supply those conditions. [Target UnitAura declarations](https://github.com/Gethe/wow-ui-source/blob/09b9db7948abc9b9648dedaab51eb0cf3ee67b31/Interface/AddOns/Blizzard_APIDocumentationGenerated/UnitAuraDocumentation.lua).

## Native graphic lifecycle and region layout

`SPELL_ACTIVATION_OVERLAY_SHOW` supplies a graphical owner ID, file ID, location and scale; `HIDE` supplies an owner ID or nil for all. These public events describe graphic lifecycle, not remaining duration. They are kept separate from native aura timing. Compound left/right and top/bottom locations expand into individual regions. A second proc does not clear another region's timer. [Overlay event declarations](https://github.com/Gethe/wow-ui-source/blob/09b9db7948abc9b9648dedaab51eb0cf3ee67b31/Interface/AddOns/Blizzard_APIDocumentationGenerated/SpellActivationOverlayDocumentation.lua).

The audited native layout uses a 204.8-unit long side and 102.4-unit short side. CarGOUI anchors public wrappers to the appropriate edge of the native root frame, placing the number at each graphic's center and adding the saved region offset. The event scale changes graphic size; outside regions additionally have a fixed 102.4-unit gap. The native root's public layout scale is used only for geometry. No native child visibility, text, alpha, aura instance, or cooldown is read to derive game state. The default Native mode leaves Blizzard's graphic and animations intact. Proc Appearance v2 optionally replaces a verified graphic with addon-owned presentation; its narrow alpha-only suppression contract is documented in [the presentation audit](PROC_APPEARANCE_V2.md). Native Aura timer ownership is unchanged. [Exact layout implementation](https://github.com/Gethe/wow-ui-source/blob/09b9db7948abc9b9648dedaab51eb0cf3ee67b31/Interface/AddOns/Blizzard_FrameXML/SpellActivationOverlay.lua).

There is no audited API that replays or enumerates active screen graphics. `IsSpellOverlayed` is not used as proof of a particular screen region. Startup uses explicitly mapped timer-aura filters (not necessarily the graphical owner ID) and the mapped native layout, then receives exact public lifecycle events. Legacy/event-only candidates stay gated until the corresponding native event. A SpellActivationOverlay database row proves a graphical owner, not by itself a duration-bearing buff alias. In particular, the hidden second Fingers of Frost owner must not be synthesized by comparing or counting the main buff's applications. These distinctions and mapping-specific confidence/limitations are listed in `MAGE_PROC_COVERAGE.md`.

## Restricted frame ownership and style

The native provider invokes `initializeFrame` before applying `DenyTaintedAccessWhenAurasAreSecret`. All button/FontString setup takes place in that callback. The helper does not retain the native button or text as a state source. An addon-owned Font object is assigned once; existing appearance logic changes that Font object, and public wrapper geometry handles scale/position. This preserves per-region Proc RGB (or dynamic class fallback) and specialization font scope without modifying Blizzard/global font objects or accessing denied native children. Native text is never measured. [Frame provider ordering](https://github.com/Gethe/wow-ui-source/blob/09b9db7948abc9b9648dedaab51eb0cf3ee67b31/Interface/AddOns/Blizzard_AuraContainer/Blizzard_AuraContainerFrameProviders.lua), [access restriction declaration](https://github.com/Gethe/wow-ui-source/blob/09b9db7948abc9b9648dedaab51eb0cf3ee67b31/Interface/AddOns/Blizzard_APIDocumentationGenerated/SimpleFrameScriptObjectConstantsDocumentation.lua).

## Shutdown, bounded reuse, and diagnostic claims

`SetEnabled(false)` immediately removes the native dynamic `UNIT_AURA` registration and queues a native dirty pass that clears slot assignments. The container and public wrapper remain shown with zero alpha so this pass can complete and disable copied duration bindings. Hiding them before the pass would suspend cleanup. No addon OnUpdate, buff scan, or periodic timer is installed. Native dirty processing runs once when requested, and its recurring pandemic update is unused. The native static `AURA_DATA_PROVIDER_SWITCH` registration remains on the bounded reusable container; this is not an active aura monitor. [Native event registration](https://github.com/Gethe/wow-ui-source/blob/09b9db7948abc9b9648dedaab51eb0cf3ee67b31/Interface/AddOns/Blizzard_AuraContainer/Blizzard_AuraContainer.lua), [dirty processing and disabled-state clearing](https://github.com/Gethe/wow-ui-source/blob/09b9db7948abc9b9648dedaab51eb0cf3ee67b31/Interface/AddOns/Blizzard_AuraContainer/Blizzard_ManagedAuraContainer.lua).

Slots are cached by stable entry identity and never reassigned to a different aura. Repeated proc triggers, Options toggles and specialization returns reuse them. Counts report configured native slots and requested tracking, not secretly observed active buffs. Diagnostics say **Native tracking** rather than claiming Lua knows the effect is present. The shared Data package's static code/SavedVariables loading boundary is unchanged.

## alpha.15 capability and mapping boundary

Adapters explicitly advertise Proc capability version 1. The shared helper runs only the selected spec factory and filters verified learned-driver conditions, never hidden timer-aura knowledge. Mobility refreshes merge their entries with the independent Proc catalogue. Three lightweight catalogue-change callbacks remain available when Mobility is disabled or the Proc catalogue is empty; empty catalogues do not register Proc business events or allocate native slots.

The compiler validates unique stable Proc/region IDs, explicit graphical sources, source-to-region membership and owner conflicts before monitoring. Legal one-owner-to-many-definition mappings require `shared=true` on every participating source; unmarked conflicts fail with diagnostics rather than overwriting another definition. Owner/texture/location dispatch uses the current index and updates only affected definitions. Alternative graphical stages retain separate observed lifecycle state but share the stable timer slot; a late HIDE cannot close another observed active stage or resurrect an unseen stage.

An existing pooled region refuses a different Aura provider or configuration scope. Its old native slot is disabled and a precise error is reported; it is never silently retargeted and user XY/RGB is not discarded. None of the new data changes the existing Mage Aura/region identities. All class-specific admission decisions, including split graphical owner/timer IDs, are in [PROC_COVERAGE.md](PROC_COVERAGE.md). A declared finite duration in those source tables is audit evidence only and is never passed to a runtime binding.

## Validation boundary

- Offline fixtures simulate aura membership, duration refresh, partial consumption and native visibility separately from combat and secrecy flags. Access/readback tripwires must remain enabled.
- Missing native templates or binding APIs produce an explicit unsupported status, with no fabricated timer or out-of-combat-only fallback presented as complete combat support.
- No live WoW client is attached to this development environment. Native secure-environment behavior, overlay event replay, exact timer placement, and mapping-specific hidden-aura behavior remain target-client acceptance items.
- No client CPU or memory number is inferred from mocks or ZIP size. In-game diagnostics must be measured on the actual target build.

## Stock graphic preference edge

The pinned stock manager ignores SHOW when `displaySpellActivationOverlays` is false and exposes no Lua replay on re-enabling. CarGOUI records those ignored SHOW regions as publicly hidden; toggling the preference alone does not replay their numbers. Initial exact-aura bootstrap cannot prove historical graphic presence. Reload synchronization and hidden owner-aura matching remain explicit target-client acceptance items.

Clearcasting now filters timer Aura 263725 while tracking three distinct native graphical owners 1277420/1277421/1277422. Its earlier 276743-only assumption was incomplete. Source evidence and the remaining client confirmation boundary are documented in [CLEARCASTING_ALPHA13.md](CLEARCASTING_ALPHA13.md).
